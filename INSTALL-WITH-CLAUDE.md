# Installing Arsenal with Claude Code

For an AI coding agent (Claude Code or similar) that a player has asked to install, update or
remove Arsenal in their S.T.A.L.K.E.R. GAMMA. Player: open Claude Code in your GAMMA folder
(where `ModOrganizer.exe` is) and paste:

> Install Arsenal by following https://raw.githubusercontent.com/devinhorowitz/GAMMA-Arsenal-App/main/INSTALL-WITH-CLAUDE.md

Agent: follow these steps in order. Say what you are about to do before each change, and stop
and ask whenever something doesn't match what this guide describes.

## Rules

- Change only `mods\Arsenal` and one line of the active profile's `modlist.txt`. Leave every
  other mod, setting and file alone.
- Never delete. Move anything you replace into a backup folder (below) and say where it went.
- Never press, start or suggest the GAMMA launcher's **Update** button; it can reset the
  player's mod list.
- MO2 and the game must be closed before you touch `modlist.txt`: MO2 writes that file when it
  exits and would silently undo your edit.
- Don't start the game yourself unless the player asks; they start it as they usually do.

## 1. Check the folder and what's running

1. The working folder must hold `ModOrganizer.exe`, `ModOrganizer.ini`, `mods\` and
   `profiles\`. If not, ask the player where their GAMMA folder is.
2. Run `tasklist`. If `ModOrganizer.exe` or any `Anomaly*.exe` is listed, ask the player to
   close MO2 and the game, then check again.
3. In `ModOrganizer.ini`, `selected_profile=@ByteArray(<name>)` is the active profile (GAMMA's
   is `G.A.M.M.A`); its mod list is `profiles\<name>\modlist.txt`. `gamePath=@ByteArray(...)`
   is the Anomaly folder (backslashes are doubled there).

## 2. Is it installed already?

Arsenal is installed if a folder under `mods\` (normally `Arsenal`) has
`gamedata\scripts\arsenal_mcm.script`. Its version is the `VERSION = "x.y.z"` line in that
script. Below, `<folder>` is that folder's name, or `Arsenal` for a new install. Installed and
current: say so and stop. Installed and older: this is an update.

## 3. Download and check the release

1. Read `https://api.github.com/repos/devinhorowitz/GAMMA-Arsenal-App/releases/latest`. Take the
   asset named `Arsenal-<version>.zip`: its `browser_download_url` and its `digest`
   (`sha256:...`).
2. Download it into a new folder outside `mods\`, such as `downloads\arsenal-<version>\`.
3. Compute its SHA-256 (`certutil -hashfile <zip> SHA256`, or Python's hashlib). It must equal
   the digest. If it doesn't, tell the player and stop.
4. List the zip. It holds one folder, `Arsenal`, with `gamedata\`, `README.md` and `LICENSE`.
   Anything else: stop and ask.

## 4. Install

1. For an update, move `mods\<folder>` to `mods_backup\<folder>-<old version>-<date>` in the
   GAMMA folder.
2. Extract what is inside the zip's `Arsenal` folder to `mods\<folder>`, so that
   `mods\<folder>\gamedata\` exists.
3. Write `mods\<folder>\meta.ini` so MO2 shows the version (CRLF line endings):

   ```
   [General]
   gameName=stalkeranomaly
   modid=0
   version=<version>
   installationFile=Arsenal-<version>.zip
   ```

## 5. Enable it in MO2's mod list

1. Copy `modlist.txt` to `modlist.txt.before-arsenal-<date>` beside it.
2. If a line reads `+<folder>` or `-<folder>`, make it `+` and change nothing else.
3. Otherwise insert `+<folder>` as the first line after the `# This file was automatically
   generated by Mod Organizer.` comment. Arsenal shares no file with any other mod, so its
   place doesn't matter, and this is where MO2 puts a new mod.
4. Keep the file's CRLF line endings and every other line byte for byte. Read it back and
   confirm that the only difference is the one line.

## 6. Requirements

- **MCM** comes with GAMMA.
- **Mod App Creator (MAC)** gives Arsenal its PDA tile. It is present if an enabled mod (`+` in
  `modlist.txt`) has `gamedata\scripts\mac_mcm.script`. Without it Arsenal still works: the
  player binds a key in **MCM > Arsenal**. MAC is at
  https://www.moddb.com/mods/stalker-anomaly/addons/mod-app-creator-mac (the player downloads
  it; don't download it yourself unless they ask).

## 7. First launch

Tell the player: start the game as usual (with Seasons of the Zone installed, that is
`play.bat`), load a save, open the PDA and the Arsenal tile (or the MCM key), then quit and tell
you. Then read `<gamePath>\appdata\logs\xray_<Windows user name>.log` and report:

- lines containing `STACK TRACEBACK` or `FATAL` (search without case);
- lines starting `[arsenal]` or `Arsenal:`, Arsenal's own error reports. `[arsenal] PDA
  (silenced):` lines are not errors: they are its PDA messages, logged instead while the player
  has them switched off;
- `$MAC: Added app: arsenal`, which means the PDA tile is in place.

No traceback and no error reports mean it is working. Arsenal works in an existing save;
nothing else is needed.

## Updating, removing

- **Update:** the same steps; the old copy goes to `mods_backup`. Arsenal's MCM settings and
  what each save has learned are kept.
- **Remove:** with MO2 closed, change `+<folder>` to `-<folder>`; to take it out of MO2 too,
  move `mods\<folder>` to `mods_backup`. Saves made with it still load.

## If something's wrong

- **No Arsenal tile:** MAC isn't installed or enabled (the log says `[arsenal] Mod App Creator
  not found; no tile`); use the MCM key.
- **Errors in the log:** show the player the lines, then open an issue at
  https://github.com/devinhorowitz/GAMMA-Arsenal-App/issues with the log attached.
